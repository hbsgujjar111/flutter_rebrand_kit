## 1.0.0

- Initial release.
- Support for app name change (iOS & Android).
- Support for package ID / Bundle ID change across Gradle and Xcode.
- App version and build number bumping in `pubspec.yaml`.
- Launcher icon generator for iOS & Android mipmaps.
- Android notification icon generator with automatic silhouette conversion.
- Smart splash screen generator with safe padding margins.
- Google Play Store marketing assets generator (512x512 icon & 1024x500 banner).
- Standalone configuration file (`rebrand_kit.yaml`) support.
